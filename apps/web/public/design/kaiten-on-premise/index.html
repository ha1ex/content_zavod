Как проходит внедрение

Команда Кайтен будет рядом на всех этапах: от заявки до работы всей команды

1ЗаявкаЗаполните короткую форму — менеджер свяжется с вами в течение рабочего дня, чтобы назначить встречу для демонстрации системы
2Ознакомительный доступТестируете Кайтен, модули и функции на реальных задачах команды, без риска для рабочих данных
3Согласование инфраструктурыСверяем требования к серверу с вашим ИТ‑отделом, чтобы обойтись без внеплановых закупок
4УстановкаВы выбираете варианты установки системы на вашем сервере: самостоятельно или с нашей помощью
5Обучение командыПроводим вебинары и даем материалы, чтобы сотрудники начали работать без лишних вопросов
6Поддержка на связиВыделенная линия поддержки остается с вами после запуска

Отвечаем на вопросы о коробочной версии Кайтен

В отличие от облачной версии, владельцы коробочного решения Кайтен полностью независимы от разработчика. Могут самостоятельно управлять обновлениями и бэкапами, внедрять Кайтен в инфраструктуру своей компании, настраивать широкий спектр интеграций.

Эта версия предназначена для компаний, которые предпочитают хранить все данные внутри своей ИТ‑инфраструктуры и самостоятельно отвечать за их сохранность.

Все данные хранятся на сервере вашей компании, коробочная версия Кайтен полностью независима от производителя. Вы имеете исключительный доступ к информации, политике безопасности и резервным копиям.

В отличие от облачной версии, в которой мы отвечаем за соответствие требованиям безопасности, в коробочной версии вы сами можете настраивать необходимый уровень шифрования.

Обновление Кайтен — это обновление версий всех его docker-образов на максимально доступные. Для их хранения и распространения мы используем свой собственный реестр docker-образов, который расположен в РФ и работает по защищенному https-протоколу.

Варианты обновления:

  • Кайтен в K8s. Обновление происходит вручную вашим системным администратором, который обновляет версии docker-образов компонентов Кайтен на актуальные.
  • Кайтен в Docker Compose. Доступно автоматическое обновление docker-образов по расписанию через предоставляемую нами утилиту.

Требуемые ресурсы и вариант развертывания Кайтен напрямую зависят от общего планируемого количества пользователей и от максимального количества пользователей, которые будут единовременно работать в Кайтен.

Если количество пользователей не превышает 1000, мы рекомендуем устанавливать Кайтен в Docker Compose на одном виртуальном / физическом сервере. Рекомендуемое кол-во ресурсов на сервере в таком случае: 8 vCPU, 16ГБ RAM, 250ГБ+ SSD-диск.

При количестве пользователей более 1000 рекомендуется устанавливать Кайтен в K8s. Количество нод, реплик подов и необходимые ресурсы для каждого компонента Кайтен можно рассчитать самостоятельно в нашем калькуляторе ресурсов (для доступа потребуется регистрация).

Часть интеграций работает нативно (GitLab, GitHub, Telegram, MAX), часть — через открытый API, часть находится в разработке. Пришлите список нужных систем — уточним точный статус по каждой.

Да, для работы с серверной версией Кайтен подключение к сети Интернет необязательно. Вы можете использовать ПО в локальной сети компании.

Да, приобретая серверную версию Кайтен клиент получает подробный пакет инструкций по установке и эксплуатации системы.
