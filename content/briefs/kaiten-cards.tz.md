# ТЗ на лендинг — kaiten-cards

> Сгенерировано фабрикой ТЗ (Контент-завод Кайтен) из сырых данных. Документ для ревью командой; машинный бриф — `content/briefs/kaiten-cards.json`.

## Summary

Лендинг «Задачи» Кайтена (/features/cards/). Режим custom: состав блоков и тексты 1-в-1 с текущей страницы kaiten.ru/features/cards/, layout не применяется, лишние блоки не добавляются. Логика страницы: первый экран про то, что вся информация по задачам собирается в карточках → свойства карточки (метки, типы задач, вложения, размер, чек-листы, чат, сроки, пользовательские поля) → четыре сценария работы с карточками: данные и общение в одном месте, шаблоны для типов задач, блокировки, движение карточек по этапам → форматы отображения задач (доски, списки, таблицы, таймлайн, календарь, отчеты) → связи между карточками и иерархия задач → запланированные задания для повторяющихся задач → автоматизации «если — то» → уведомления о действиях с карточками → финальный призыв попробовать Кайтен. Видео и скриншоты исходной страницы заменяются упрощенными интерфейсными мокапами из библиотеки контент-завода (домен PM).

## Аудитория

- **Основная:** Руководители команд и отделов, которые ведут задачи на досках и хотят, чтобы вся информация по каждой задаче хранилась в одном месте
- **Принимает решение:** Руководитель отдела или проектного офиса — выбирает сервис для работы с задачами команды
- **Роли:** Тимлиды и руководители команд, которые ставят задачи и следят за сроками, Руководители проектов, которым нужно декомпозировать крупные задачи и видеть прогресс подзадач, Участники команд, которые ведут свои задачи в карточках и общаются с коллегами, Администраторы, которые настраивают типы задач, шаблоны и уведомления

**Боли:**
- Информация по задаче разбросана по почте, мессенджерам и файлам — карточка собирает поля, описание, вложения и чат в одном месте
- Однотипные задачи каждый раз заводятся вручную с разным набором полей — шаблоны для типов задач задают нужные поля и правила
- Непонятно, почему задача стоит — блокировка показывает причину или блокирующую карточку
- Крупные задачи сложно разбить на части и отследить прогресс — связи строят иерархию родительских и дочерних карточек
- Регулярные задачи забываются, а о важных событиях узнают поздно — карточки по расписанию и уведомления в удобном канале

**Критерии выбора:**
- В карточку можно добавить любые поля, ответственных, сроки, описание и вложения
- Разные типы задач со своими шаблонами и правилами
- Прозрачный ход работы: этапы доски, визуальные сигналы и метки
- Несколько форматов отображения одних и тех же задач
- Автоматизация повторяющихся задач и действий, уведомления в удобном канале

**Возражения:**
- Не потеряются ли данные по задаче — все данные и вложения хранятся в карточке
- Не придется ли каждый раз заполнять одно и то же — шаблоны для типов задач и карточки по расписанию
- Как понять, что мешает задаче двигаться — блокировка с причиной или блокирующей карточкой
- Не будет ли шума от уведомлений — вы сами решаете, о каких действиях и где их получать

2. **media_copy — «Все данные и вложения будут храниться в одном месте»** — Показать свойства карточки: метки, типы задач, вложения, размер, чек-листы, чат, сроки, пользовательские поля _(визуал: Окно карточки проекта: блокировка, метки, срок, чек-лист, дочерние карточки, панель комментариев)_
3. **features — четыре сценария работы с карточками** — Данные и общение в одном месте, шаблоны для типов задач, блокировки, движение карточек по этапам _(визуал: Мини-мокапы галереи фич: комментарии, кастомные поля и типы, блокировка задач, канбан-доска)_
4. **view_switcher — «Выберите удобный формат отображения задач»** — Шесть форматов отображения одних и тех же задач _(визуал: Пространство в видах доски, списка, таблицы, таймлайна, календаря и отчетов)_
5. **media_copy — «Добавляйте связи между карточками»** — Заголовок раздела про связи и иерархию задач _(визуал: Без визуала — текстовая шапка раздела)_
6. **media_copy — «Связи помогают декомпозировать крупные задачи»** — Родительские и дочерние задачи внутри карточки, прогресс подзадач _(визуал: Поток карточки по доске со связью с родительской карточкой)_
7. **media_copy — «Создавайте запланированные задания»** — Карточки по расписанию для регулярных задач _(визуал: Календарь и карточка по расписанию «1 число (ежемесячно)»)_
8. **media_copy — «Избавьтесь от рутины»** — Автоматизации «если — то» и ссылка на страницу автоматизаций _(визуал: Конструктор правила автоматизации: событие и условие)_
9. **media_copy — «Получайте уведомления»** — Уведомления о действиях с карточками в удобном канале _(визуал: Настройка бота и доставка уведомлений в Telegram, Max, мобильное приложение)_
10. **final_cta** — Финальный призыв попробовать Кайтен _(визуал: Минималистичная доска)_

### hero

Заголовок: Соберите всю информацию по задачам в карточках
Подзаголовок: Вы можете добавить в карточки неограниченное количество полей с информацией, назначить ответственных, установить сроки, добавить подробное описание и общаться с коллегами.
Кнопка: Попробовать Кайтен

### media_copy — данные и вложения
**Все данные и вложения будут храниться в одном месте и не потеряются.**

Пункты: Метки · Типы задач · Вложения · Размер · Чек-листы · Чат · Сроки · Пользовательские поля

### features — сценарии
**Соберите все нужные данные и коммуникации в одном месте**

1. Соберите все нужные данные и коммуникации в одном месте — Создавайте карточки для каждой задачи, добавляйте подробное описание и общайтесь с коллегами в чате.
2. Создавайте шаблоны для разных типов задач — Для разных категорий задач создавайте готовые шаблоны с нужными полями и описаниями. Для каждого типа задач задавайте свои правила и строгий поток.
3. Блокируйте карточки, над которыми не можете продолжить работу — Если по какой-то причине вы не можете в данный момент выполнить задачу, добавьте предупреждение-блокировку и укажите причину или блокирующую карточку.
4. Сделайте процесс работы над задачами прозрачным и управляемым — По мере выполнения работы передвигайте карточки на доске от одного этапа к другому, пока задача не будет готова. Добавьте визуальные сигналы и метки, чтобы быстро ориентироваться в задачах на досках.

**Выберите удобный формат отображения задач на рабочем пространстве**

Вы сами решаете, о каких действиях с задачами получать уведомления. И где их получать.
Узнавайте о важных событиях, оставляйте комментарии и ставьте задачи там, где вам удобно

## Визуалы

- **hero** — Анимированный первый экран hero-screen-interface: доска «Задачи команды» с колонками Очередь / В работе / Готово, карточки с метками, сроками и ответственными; курсор переносит карточку между этапами
- **media_copy — данные и вложения** — Окно карточки проекта «Редизайн сайта» (window-project-modal): блокировка, метки, срок, бюджет, чек-лист, дочерние карточки и комментарии
- **features — сценарии** — Мини-мокапы галереи фич FeatureMocksV01: «Комментарии и упоминания», «Кастомные поля и типы», «Блокировка задач», «Канбан-доски»
- **view_switcher** — Одно пространство в шести видах (workspace-view-*): доска, список, таблица, таймлайн, календарь, отчеты
- **media_copy — связи, расписание, автоматизации, уведомления** — Поток карточки со связью с родительской (window-card-flow), плитка «Повторяющиеся задачи» (tile-recurring-tasks), конструктор правила (window-rule-trigger), плитка «Боты и уведомления» (tile-notifications)
