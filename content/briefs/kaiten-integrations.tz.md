# ТЗ на лендинг — kaiten-integrations

> Сгенерировано фабрикой ТЗ (Контент-завод Кайтен) из сырых данных. Документ для ревью командой; машинный бриф — `content/briefs/kaiten-integrations.json`.

## Summary

Лендинг «Интеграции» Кайтена (/features/integrations/). Режим custom: состав блоков и тексты 1-в-1 с текущей страницы kaiten.ru/features/integrations, layout не применяется, лишние блоки не добавляются. Логика страницы: первый экран про подключение любимых инструментов к Кайтен без сложных настроек → готовые интеграции: GitHub, GitLab, Telegram, Slack, календарь, Webhook, Tilda, Google Forms, Zapier → открытый API для собственных интеграций, аналитики и утилит → финальный призыв зарегистрироваться. Логотипы и скриншоты исходной страницы заменяются мокапами контент-завода (домен PM): карта интеграций, плитки галереи фич, документация Kaiten API.

## Аудитория

- **Основная:** Команды, которые уже работают в нескольких сервисах — репозитории, мессенджеры, календари, формы сайта — и хотят, чтобы задачи из них попадали в Кайтен без ручного переноса
- **Принимает решение:** Руководитель команды или отдела, ИТ-руководитель — решает, какие сервисы связать с Кайтеном и нужна ли собственная интеграция через API
- **Роли:** Тимлиды и руководители команд разработки, которые связывают коммиты и ветки с задачами, Руководители проектов и отделов, которым важно получать уведомления и сроки в привычных сервисах, Маркетологи и сотрудники поддержки, которые принимают заявки с сайта и из форм, Разработчики и администраторы, которые настраивают собственные интеграции через API

**Боли:**
- Задачи и события живут в разных сервисах — интеграции связывают коммиты, ветки и пулл-реквесты с карточками Кайтена
- Уведомления о задачах приходится проверять в отдельной вкладке — Telegram и Slack присылают их в привычную беседу
- Заявки с сайта и из форм переносятся в трекер руками — Webhook, Tilda и Google Forms создают карточки сами
- Сроки задач не видны в личном календаре — Кайтен подгружает их автоматически
- Нужного сервиса нет в списке — Zapier и открытый API позволяют собрать свою интеграцию

**Критерии выбора:**
- Подключение без сложных настроек, в несколько кликов
- Готовые интеграции с сервисами разработки, мессенджерами, календарем и формами
- Возможность принимать заявки из любых систем
- Открытый API для собственных интеграций и выгрузки данных в аналитику

**Возражения:**
- Настройка потребует программиста — готовые интеграции подключаются в несколько кликов
- Нашего сервиса нет в списке — через Zapier доступно более 50 приложений, а через открытый API можно создать свою интеграцию
- Данные останутся заперты в трекере — через API их можно получать для систем аналитики и отчетов
