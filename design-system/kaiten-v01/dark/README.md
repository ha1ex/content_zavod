# Kaiten Landing DS — тёмная тема (V01-dark)

Слепок стилей тёмного лендинга из Figma-файла **«Landing DS»**.
Макет-источник — лендинг конференции «AI в управлении компанией: тренды 2026».

| Артборд | Node | Размер |
| --- | --- | --- |
| Desktop | `2732:43296` | 1920 × 8384 |
| Mobile | `2732:43758` | 360 × 8893 |

Файл: <https://www.figma.com/design/6M8lLx2PgVTxwXMeRiOVH4/Landing-DS>

## Состав

| Файл | Что это |
| --- | --- |
| `theme-dark.css` | CSS-переменные + классы компонентов, готово к подключению. |
| `tokens.dark.json` | Машинный слайс тех же значений с провенансом каждого. |
| `reference/dark-desktop-1920.png` | Полный десктопный макет (даунскейл до 960px). |
| `reference/dark-mobile-360.png` | Полный мобильный макет, 1:1. |

## Главный принцип темы

Это **не отдельная палитра**. Все поверхности — брендовый фиолетовый `#7d4ccf`,
положенный на тёмный фон с альфой **8 / 12 / 15 / 24 / 48 %**:

| Альфа | Где |
| --- | --- |
| 12 % | чипы, плитки иконок, вторичная кнопка, карточки |
| 15 % | бейджи (`Badges/Primary/Background`) |
| 24 % | бордер выделенной карточки, чипы на мобилке |
| 48 % | бордер вторичной кнопки (`Brand 48K`) |

Нужен новый уровень глубины — берите следующую альфу, а не новый хекс.
Плоские эквиваленты (`#25163d`, `#311d51`, `#4f2f83`, `#201334`, `#2b1a47`)
лежат в токенах для мест, где полупрозрачный слой недоступен: SVG-заливки,
e-mail-вёрстка, статичный экспорт.

## Фон: десктоп ≠ мобилка

Десктоп стоит на `#190f29` (`Background/White/Primary`),
мобилка — на более глубоком `#130b1f` (`Background/White/Secondary`).
`theme-dark.css` переключает это на брейкпоинте `max-width: 767px`.
Из-за смены основы отличаются и плоские эквиваленты оверлеев — см. таблицу выше.

## Что тема НЕ меняет

Типографика (Roboto, шкала xs…7xl), спейсинги, радиусы и сетка 1216/32
наследуются из [`../tokens.json`](../tokens.json) без изменений.
В `theme-dark.css` они продублированы только чтобы файл был самодостаточным.

## Три градиента

| Токен | Направление | Где |
| --- | --- | --- |
| `--kd-grad-pill` | 90° `#47317d → #0d6e93` | бейджи-пилюли секций и дат |
| `--kd-grad-heading` | 90° `#7d4ccf → #00cffe` | градиентная часть H2, `background-clip: text` |
| `--kd-grad-accent` | 180° `#00cffe → #7d4ccf` | цифры метрик и «AI» в H1 |

Плюс два фоновых: `--kd-grad-card` (карточка-метрика) и `--kd-grad-cta`
(блок регистрации, диагональ фиолетовый → синий).

## Инверсии, о которых легко забыть

- **Поля ввода остаются светлыми.** Белый фон, текст `#424242`, бордер `#d1d5db` —
  так в макете, это не ошибка выгрузки.
- **Футер — единственная светлая брендовая зона.** Сплошной `#7d4ccf`,
  над ним декоративная растровая «волна» (ассет не экспортирован, виден в `reference/`).
- **Фото спикеров — чёрно-белые** (`filter: grayscale(1)`).

## Провенанс значений

В обоих файлах каждое значение помечено:

- `var` — из Figma-переменных (`get_variable_defs`), точное;
- `px` — снято пипеткой с полноразмерного рендера макета, точное;
- `derived` — в макете такого состояния нет, выведено по системе.

Под `derived` попали только состояния кнопок (`hover`, `active`) и фокус поля ввода.
Их стоит подтвердить у дизайнера перед продакшеном.

## Ограничения

- Этот файл — **референс**, в сборку он не входит. Рабочая реализация темы живёт
  в [`packages/ui/src/theme-dark.css`](../../../packages/ui/src/theme-dark.css):
  она перекладывает значения отсюда на семантические токены завода (`--color-*`)
  и включается, когда в спеке стоит `theme: "dark"`. Правки палитры — там;
  сюда возвращаем только то, что реально пришло из макета.
  Как собирать тёмный лендинг и где грабли —
  [`wiki/design-system/dark-theme.md`](../../../wiki/design-system/dark-theme.md).
- **`--kd-grad-cta` здесь описан неточно.** Замер ноды `2732:43522` в нативном
  размере даёт горизонтальный двухточечный `90deg #311e52 → #133e5e`, а не
  диагональ по четырём углам: верх и низ идентичны, середина лежит ровно на
  линейной интерполяции. Углы выше сняты с общего артборда, где поверх плашки
  лежит подсветка страницы. Верить замеру ноды.
- Светлый `packages/ui/src/tokens.css` собирается из `../tokens.json` командой
  `pnpm harness -- wiki sync` и правится только через неё.
- Растровые ассеты макета (3D-куб героя, подарочная коробка, «волна» футера,
  логотипы партнёров, фото спикеров) не экспортированы — в `reference/` они
  видны только как часть скриншота.
- `get_design_context` и `get_metadata` по этим нодам не отдаются: MCP-транспорт
  Figma обрывает ответ на ~26 КБ. Поэтому геометрия снята измерением рендера,
  а не из дерева слоёв.
