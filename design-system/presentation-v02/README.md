### Цвет в процессных лентах

Цвет несет смысл, а не порядок. Пары 100/12 из дизайн-системы:

| Модификатор | Значение | Цвет |
|---|---|---|
| без модификатора | обычный шаг | сиреневый |
| `.is-strong` | старт и финиш | залитый сиреневый, белый текст |
| `.is-success` | реализовано, завершено | зеленый |
| `.is-danger` | отклонение, блокер | красный |
| `.is-warning` | в работе, ожидание | оранжевый |
| `.is-info` | информация | голубой |

Раскрашиваем только те шаги, у которых статус есть на самом деле. Остальные
остаются сиреневыми — иначе лента превращается в радугу и цвет перестает
что-либо значить.

## Тема Light

Стиль сохранен как тема **Light** — `theme-light.css`. Это базовая светлая
тема шаблона V02: белое полотно, темный текст, серые фреймы, сиреневый акцент,
размытая подложка по нижнему краю.

Подключение — после базового файла, с атрибутом на корне:

```html
<html lang="ru" data-theme="light">
<link rel="stylesheet" href="kaiten-slides.css" />
<link rel="stylesheet" href="theme-light.css" />
```

Тема задает только цвет и декор. Сетка, типографика и компоненты живут в
`kaiten-slides.css` и от темы не зависят — новая тема это только новый файл
рядом с `theme-light.css`.

### Три стиля

| Стиль | Файл | Статус |
|---|---|---|
| **Light** | `theme-light.css` | готов — снят со слайдов 154-618, 163-1748, 164-2258, 166-2832, 218-2366 |
| **Dark** | `theme-dark.css` | готов — снят со слайдов 149-583 и 163-1250 |
| **Сравнение** | `theme-comparison.css` | готов — снят со слайда 3-1837 |

Переключение тем: на `<html>` ставится `data-theme` (текущая) и
`data-themes` (список подключенных, через пробел). Если тем больше одной,
`kaiten-slides.js` сам добавляет кнопку переключения в навигацию.
Файлы тем подключаются в том же порядке, что перечислены в `data-themes` —
Light объявляет значения и на `:root`, поэтому идет первой.

### Чем Dark отличается от Light

| | Light | Dark |
|---|---|---|
| Полотно | `#ffffff` | `#190f29` |
| Текст | `#2d2d2d` / `#757575` | `#ffffff` / белый под 70% |
| Фрейм | `#f2f2f2` | сиреневый под 24% |
| Акцентный фрейм | `#efe9f9`, заголовок сиреневый | сплошной `#7d4ccf`, заголовок белый |
| Иконочная плашка | светлая подложка, сиреневая иконка | залитая сиреневым, иконка белая |
| Свечение снизу | 30.7px, обычное наложение | 42px, наложение `screen` — светится, а не сереет |
| Логотип | надпись темная | надпись белая (`kaiten-logo-on-dark.svg`) |

Правило акцента в темной теме обратное: залитый сиреневый там норма, потому
что на темном фоне светлая подложка не читается. Сильное выделение — сплошной
акцентный фрейм, один на слайд.

В светлой теме темных плашек не используем вообще — командная строка тоже
светлая, на `--surface-frame`.

### Чем «Сравнение» отличается от Light

Палитра, типографика, сетка и компоненты те же. Отличие одно — зонирование
верхнего колонтитула:

- Во всю ширину слайда лежит ступенчатая плашка `#F2F2F2` высотой 119px.
  Слева она тонкая, 24px, справа утолщается до 119px; переход идет диагональю
  под 45° со скруглениями (полка до x=1301, скос до x=1447).
- В толстой части справа — пара логотипов: конкурент высотой 32px,
  разделитель `#EEEEEE` толщиной 2.8px в режиме `multiply`, логотип Кайтена
  высотой 48px. Все на отметке y=36, правое поле 60px.
- Заголовок слайда опускается с 36px на 60px — ниже тонкой части плашки.
- На обложке заголовок стоит вверху слева, а не по центру по вертикали.

Разметка колонтитула — компонент `.brand-pair` вместо обычного `.mark`:

```html
<div class="brand-pair">
  <img class="rival" src="assets/rival-bitrix24.svg" alt="Битрикс24" />
  <span class="brand-divider"></span>
  <img src="assets/kaiten-logo.svg" alt="Кайтен" />
</div>
```

Для другого конкурента кладем его логотип в `assets/` и меняем `src` — больше
ничего трогать не нужно.

Контракт темы — набор переменных, которые она обязана объявить. Ничего кроме
них переопределять не нужно, все компоненты читают только их:

```
палитра      --neutral-000…950, --violet-100, --violet-12
роли         --text-primary, --text-secondary, --text-accent,
             --surface-page, --surface-frame, --surface-accent,
             --border-default, --action-primary
декор        --glow-cyan, --glow-magenta,
             --glow-opacity, --glow-blur, --glow-blur-cover
```

**Правило акцента в светлой теме.** Залитая сиреневая плашка — сильное
выделение, ее держим для одного действительно важного элемента на слайде.
Все остальное — светлая подложка `#efe9f9` с сиреневым содержимым. Это
включается модификатором `.is-accent`: не больше одного на слайд.

## Правила текста

- **Буква «е» не используется** — везде пишем «е»: не «перестает», а
  «перестает»; не «верстка», а «верстка». Правило распространяется на все
  тексты слайдов и на `content.md`.

## Модульная сетка

Снята со слайда «Модульная сетка» (node `218-2366`), проверена на `166-2832`,
`163-1748`, `164-2258` — совпадает до пикселя.

```
по горизонтали   1920 = 60 + 1800 + 60
                 1800 = 4 колонки по 429 + 3 гаттера по 28
по вертикали     1080 = 36 + 52 + 79 + 864 + 49
                  864 = 2 ряда по 418 + гаттер 28
модуль           429 × 418, радиус 16
```

Блоки собираются из модулей: 1 модуль — 429, 2 модуля — 886, 3 модуля — 1315,
4 модуля — 1800. Классы: `.cols-2` (886+886), `.cols-4`, `.grid-2x2`, `.grid-4x2`.
Гаттер один и тот же по обеим осям — 28px (`--gap`).

## Применение цвета

Собрано по фактическим заливкам четырех слайдов шаблона.

| Роль | Цвет | Где |
|---|---|---|
| Полотно слайда | `#ffffff` | фон всех слайдов |
| Текст | `#2d2d2d` | заголовки и основной текст, на всех слайдах |
| Вторичный текст | `#757575` | подписи к цифрам, пояснения пунктов |
| Фрейм | `#f2f2f2` | серые плашки и карточки-цифры |
| Акцентная поверхность | `#efe9f9` | акцентный фрейм, плашка иконки, баннер |
| Акцент | `#7d4ccf` | цифры, галочки, акцентные заголовки, залитые плашки |
| Декоративный градиент | `#6fe5ff` → `#e298ff` | размытая подложка: полоса по низу, круг на обложке |
| Логотип | `#f11f24`, `#78ffc7`, `#7d4ccf` | только знак Кайтена, больше нигде |

Правила, которые из этого следуют: цветной — только акцент и декоративная
подложка; все остальное — белый, серый и текст. Один акцентный элемент на
экран; красный и зеленый на слайдах шаблона встречаются только внутри
продуктовых скриншотов, в оформлении их нет.

## Сетка и хром

- Поля слайда: 60px по бокам, 50px сверху и снизу.
- Знак Кайтена — 46px в правом верхнем углу на всех слайдах, кроме обложки
  (там полное лого со словом слева сверху).
- Фрейм: радиус 20px, фон `#f5f5f5`; акцентный — `#efe9f9`, заголовок сиреневый.
- Иконочная плашка пункта: 64×64, радиус 12px.
- По нижней кромке — цветная полоса-градиент, как в макете.

## Как собрать новый дек

1. Скопируй `templates.html` под своим именем.
2. Оставь нужные `<section class="slide">`, замени рыбу на текст.
3. `kaiten-slides.js` сам построит навигацию — ничего подключать вручную не нужно.
4. `Ctrl+P` дает PDF: одна страница = один слайд.

## Расхождения с оригиналом — знать заранее

- **Словесная часть лого** («Кайтен» на обложке) набрана шрифтом, а не вектором:
  в Figma Slides она недоступна как SVG-ассет. Знак — вектор из
  `apps/web/public/brand/kaiten-logo-dark.svg`.
- **Описания пунктов серые** (`#757575`) — так в шаблоне презентации. В
  лендинговой дизайн-системе `design-system-kaiten-v01-landingpage` то же самое требуется
  делать темным `#2d2d2d`. Для презентаций следуем шаблону презентаций.
- **Иконки в плашках** нарисованы по мотивам макета: в Figma Slides они не
  отдаются как SVG-ассеты.
