## Слайд 2 — Что меняется

**Заголовок:** Лендинг перестает быть проектом

| Было | Стало |
|---|---|
| Каждый лендинг отнимает у фронтенд-команды дни | Бриф → страница в превью за ~1 минуту |
| Собирается «из чего попало», мимо дизайн-системы | Только компоненты из registry — «левый» блок вставить нельзя |
| Бренд-voice и качество держатся на ручном ревью | Проверки бренда, домена, a11y и бизнес-правил зашиты в пайплайн |

## Слайд 3 — Как это работает

**Заголовок:** Один конвейер от сырья до передачи в верстку

**Поток:** Сырье → Фабрика ТЗ (intake) → Гейт домена → P0–P8 → apply → Превью → Approve → Handoff (ZIP)

**Подпись:** 9 фаз с гейтом на каждой и repair-loop до 3 попыток. Фазы идемпотентны — перезапуск не ломает сделанное. API-ключи не нужны: LLM — это сам хост-агент.

---

## Слайд 4 — Почему результат не разъезжается

**Заголовок:** Качество зашито в конвейер, а не в ревью

**Цифры:** 8 доменов / 27 mock'ов · 12 валидаторов · 10 layout-плейбуков

**Гейты:**
- Брифы неизменяемы — новая итерация это новый файл
- Mock'и только из домена брифа, cross-domain reuse заблокирован
- `generated/` — derived-артефакт, руками не правится
- Единственная точка входа сборки — `agent build`

**Подпись:** Гейты машинно-enforced на трех слоях: git pre-commit, harness CLI, хуки агента.
