Страница перестает быть проектом

Было

  • Новая страница занимает у фронтенд-команды несколько дней
  • Блоки собираются вручную, мимо дизайн-системы
  • Тон бренда и качество держатся на ручной проверке

Стало

  • Бриф превращается в страницу за минуту
  • Доступны только компоненты из реестра — чужой блок не вставить
  • Проверки бренда, домена, доступности и бизнес-правил идут внутри конвейера

Качество зашито в конвейер, а не в ручную проверку

  • Брифы неизменяемы — новая итерация это новый файл
  • Макеты интерфейса берутся только из домена брифа
  • Повтор макета из чужого домена заблокирован
  • Папка generated/ — производный артефакт, руками не правится
  • Единственная точка входа сборки — agent build
  • Порядок секций сверяется со сценарием страницы
  • Тон бренда, англицизмы и доступность проверяются на каждом прогоне
