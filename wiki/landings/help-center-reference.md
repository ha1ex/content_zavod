# Reference — домен «Справочный центр» (портал помощи)

Эталон визуального набора для лендингов про **публичный портал помощи** поверх
Kaiten. Первый лендинг домена — `kaiten-help-center` (ТЗ команды, docx «Лендинг
Справочный центр», август 2026). Живой пример продукта —
[faq-ru.kaiten.site](https://faq-ru.kaiten.site/).

## Чем домен отличается

Справочный центр — **внешний портал компании-клиента**, а не рабочее
пространство трекера. У всех моков домена есть общий признак: шапка портала с
логотипом клиента («ВАШ ЛОГОТИП»), поисковой строкой и кнопкой «Создать заявку».
Пользователь портала — не сотрудник команды Kaiten, а покупатель, партнер или
сотрудник другого отдела.

Отсюда границы с соседними доменами:

| Домен | Почему не подходит |
|---|---|
| `support` (`support-board`, `request-card`) | Это **внутренние** экраны агента поддержки: доска очереди и карточка тикета с чатом. Портал показывает ту же заявку глазами обратившегося — список «Мои заявки» со статусами. Единственное пересечение — `help-center-request-card`, но он показывает обращение **как оно приходит из портала** на доску, с сервисом и пометкой «Новая заявка из портала» |
| `docs` (`docs-tree`, `kb-public`, `kb-internal`) | Это внутренняя база знаний с деревом разделов и правами доступа. У Справочного центра дерево — **публичная навигация портала** (Главная / Инструкции / Вопросы и ответы / Новости), а не структура рабочего пространства |
| `pm`, `crm`, любые доски | Канбан вместо портала не отражает продукт — блокер ревью |

И наоборот: моки `help-center-*` не ставим на лендинги про внутреннюю базу
знаний или про модуль «Служба поддержки» — там свои наборы.

## Аудитория

- Руководители службы поддержки и клиентского сервиса — снимают поток типовых
  вопросов.
- ИТ-руководители и специалисты внутреннего хелпдеска — доступы, программы,
  оборудование.
- HR-руководители — онбординг, регламенты, кадровые обращения.
- Продуктовые команды и технические писатели — документация для пользователей
  и партнеров.
- Административные службы (бухгалтерия, юристы, АХО) — внутренний сервис
  запросов.
- Действующие клиенты Kaiten, которые настраивают портал в своем пространстве.

Целевое действие — **попробовать бесплатно** (создать Справочный центр).

## Плитка в галерее мини-мокапов

Секция «Возможности Справочного центра» собрана эталонным блоком `FeatureGrid`
с `variant: "mock"` — иллюстрация каждой карточки берётся из галереи
`FeatureMocksV01` по подписи (`items[].featureTile`). Все шесть подписей —
собственные плитки домена:

| Подпись | Что изображает |
|---|---|
| `Главная страница Справочного центра` | Главная портала: строка «Структура Справочного центра» из трёх разделов (Инструкции / Вопросы / Новости) и «Подборка важных материалов» из трёх карточек с иконкой и ссылкой |
| `Новостная лента Справочного центра` | Раздел новостей: слева список выпусков с активным пунктом, справа две записи — заголовок, картинка, текст и «Читать далее»; в шапке бейдж RSS |
| `Статья компании в поиске` | Поисковая выдача: запрос «как оформить заказ» и два результата с зелёным адресом help.company.ru › инструкции и заголовком-ссылкой статьи, справа крупная серая лупа |
| `Поиск по Справочному центру` | Слева минималистичное дерево разделов (Инструкции с полосками-статьями, Вопросы, Новости), справа поисковая строка с запросом «документы» и найденные статьи |
| `Рекомендации статей в заявке` | Поле «Название» с набранным вопросом и блок «Рекомендованные статьи:» со ссылками, который Кайтен подставляет на лету |
| `Мои заявки в Справочном центре` | Раздел «Заявки»: поиск и фильтры по статусу, таблица НОМЕР / СТАТУС / НАЗВАНИЕ с тремя обращениями |

Плиток из чужих доменов в секции больше нет: «История заявок» переехала
с общей `Обращения и поддержка` на собственную `Мои заявки в Справочном центре`.

## Лексика домена

Разрешено: справочный центр, портал, раздел, статья, материал, инструкция,
вопросы и ответы, новости, поиск, рекомендованные статьи, заявка, обращение,
сервис, статус, «Мои заявки», брендирование, основной цвет, логотип, домен
компании, шаблон писем, индексация.

Запрещено (сигнал cross-domain reuse): спринт, эпик, story points, SLA-таймер
агента, воронка, сделка, лид — это лексика чужих доменов.

## Раскладка на лендинге

- Hero — `help-center-portal` (единственный крупный мок первого экрана).
- Тело — 4–6 средних моков, чередуя стороны (`mediaPosition` left/right).
- Путь пользователя — `ScenarioWalkthroughSection` из четырех шагов:
  `help-center-search` → `help-center-suggested-articles` →
  `help-center-request-card` → `help-center-requests`.
- Оформление портала — `TabbedFeatureSection` из трех вкладок:
  `help-center-branding` / `help-center-domain` / `help-center-email`.
- Финальный CTA — градиентный `FinalCta` с `visualVariant: help-center-portal-compact`
  (полный `help-center-portal` в узкой правой колонке вытягивается по высоте).
