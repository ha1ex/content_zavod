# Правила презентаций Кайтена

Действуют **только на презентации**. Лендинги — `design-system/kaiten-v01/`.

## Что общее с лендингами и не дублируется

Редполитика (`wiki/brand/redpolitika.md`), продуктовые факты
(`wiki/references/kaiten-product-facts.md`), словарь англицизмов. Это правила
бренда, они не зависят от носителя. Копий в папке презентаций быть не должно —
разойдутся за две правки, и станет непонятно, какая настоящая.

## Что своё и с лендингами пересекаться не должно

| | Лендинг V01 | Презентация V02 |
|---|---|---|
| Холст | контейнер 1216, 12 колонок | слайд 1920×1080 |
| Сетка | 12 колонок, гаттер 32 | 4 колонки по 429, гаттер 28 |
| Гарнитура | Inter | Roboto 400 / 500 / 600 |
| Шкала отступов | 4px | вертикали макета: 36, 49, 79 |
| Единицы | px и rem | cqw от ширины слайда |

Два конфликта, которые всплывали и решены в пользу шаблона презентаций:
скилл `kaiten-ux-ui-designer` предписывает Inter — в презентациях действует
Roboto; вертикали 49 и 79 не лежат на 4-пиксельной шкале — оставлены как в
макете, иначе разъезжается сетка.

## Цвет

Пары 100/12 из дизайн-системы: заливка светлая, содержимое насыщенное.

| Модификатор | Значение | Цвет |
|---|---|---|
| без модификатора | обычный элемент | сиреневый |
| `.is-strong` | старт, финиш | залитый сиреневый |
| `.is-success` | реализовано | зеленый |
| `.is-danger` | отклонение, блокер | красный |
| `.is-warning` | в работе | оранжевый |
| `.is-info` | информация | голубой |

Раскрашиваем только то, у чего статус есть на самом деле.

## Акцент

**Light:** залитый сиреневый — сильное выделение, **один на слайд**. Все
остальное — светлая подложка `#efe9f9` с сиреневым содержимым. Темных плашек
в светлой теме нет вообще, включая командную строку.

**Dark:** правило обратное. Залитый сиреневый — норма, светлая подложка на
темном не читается. Сильное выделение — сплошной акцентный фрейм, один на слайд.

## Текст

- **Буква «ё» не используется** — везде «е»: «перестает», «верстка», «сырье».
  Проверка перед сдачей: `grep -c "[ёЁ]" <файл>` должен дать 0.
- Точек в заголовках и подзаголовках нет.
- Один тезис на слайд.
- Заголовок слайда — 48/52, желательно в одну строку.
- Дальше по редполитике: англицизмы с русским аналогом заменяем, боли
  формулируем через управляемое улучшение, лозунги из denylist не используем.

## Логотип

- В углу контентных слайдов — полный логотип, знак со словом, 161×48.
- На обложке — он же, слева сверху.
- На темной теме подставляется вариант с белой надписью, знак остается цветным.
- В презентациях-сравнениях в колонтитуле стоит пара: логотип конкурента,
  разделитель, логотип Кайтена.

## Чек-лист перед сдачей

- [ ] Roboto, начертания только 400 / 500 / 600
- [ ] размеры из шкалы 72 / 48 / 36 / 30 / 24 / 20
- [ ] не больше одного залитого акцента на слайд
- [ ] цвет несет смысл, а не разнообразие
- [ ] «ё» ноль
- [ ] точек в заголовках нет
- [ ] логотип полный и в нужном варианте под тему
