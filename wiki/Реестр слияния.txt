3. Ошибки процесса
------------------


3.1 Чужой git reset --hard посреди работы

В reflog две записи reset: moving to HEAD. Снесло безвозвратно:
переименование моков в Window*, чужие незакоммиченные правки
(CtaBanner.tsx — вариант product, FeatureGrid.tsx, FeatureGridMock.tsx,
registry.json, 44 строки wiki/log.md) и правки тем презентации.

Причина, скорее всего, — параллельная сессия: в репозитории пять worktree, среди них
.claude/worktrees/bold-poincare-203375 на ветке
claude/content-factory-presentation-8b3103.

Вывод: пока в каталоге работают двое, любые незакоммиченные правки —
расходный материал. Коммитить чаще либо развести работу по worktree.


3.2 Разрушено состояние merge (моя ошибка)

Чтобы замерить эталонное число ошибок типов, я выполнил посреди слияния
git stash + git checkout origin/main -- packages/…. Это стёрло MERGE_HEAD,
и git перестал считать слияние незавершённым.

Разрешения уцелели в рабочем дереве; коммит пересобран через commit-tree
с двумя родителями, связь ветвей сохранена. Но замер стоило делать на копии,
а не в рабочем каталоге.


3.3 Дубль пропа при объединении (моя ошибка, поймана)

В FeatureGrid.tsx я склеил два описания одного и того же пропа
featureTile — получилось повторное объявление и 5 синтаксических ошибок.
Затем при вырезании дубля срезал лишние строки и сломал закрытие
FeatureCtas. Обе поломки поймал tsc, исправлены.

Вывод: объединять стороны конфликта построчно можно только когда это
разные сущности; одноимённые поля надо сверять по имени, а не по позиции.


3.4 Отклонённый пуш в Kaiten-project

remote rejected … duplicateEntries: contains duplicate file entries.
Дерево собиралось фильтром по имени папки, а git ls-tree печатает кириллицу
экранированной — старая запись не удалилась, в дереве оказались две записи
«Модуль «Автоматизации»». Пересобрано через git ls-tree -z.
