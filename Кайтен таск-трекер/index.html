Вопросы и ответы

  • Можно ли использовать Кайтен бесплатно?

    Да. Вы можете вести свои задачи бесплатно без ограничения по времени. Вы можете пригласить до 5 пользователей, создать до 5 пространств и бесконечное количество документов. Платные тарифы нужны для расширенных функций и большего количества пользователей. Подробнее о тарифах

  • Какие методологии поддерживает Кайтен?

    Канбан, Скрам и Гант — можно использовать любую отдельно или сочетать в одном пространстве. Есть также учет времени по задачам и проектам. Больше о функциях — на сайте Кайтен.

  • Нужен ли ИТ-отдел для внедрения?

    Нет. Интерфейс настраивается без программирования, регистрация и первая доска занимают около 30 минут.

  • Как перенести данные из другого сервиса?

    Экспортируйте все пространства в формате PDF, HTML или CSV. Как экспортировать данные. Скачанные файлы можно будет импортировать в Кайтен — доски с помощью CSV-файла, документы — копипастом. Как перенести задачи с помощью выгрузки в формате CSV/XLS
