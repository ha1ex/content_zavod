# Модуль «Автоматизации» — статичная выгрузка лендинга

Автономная копия страницы `/landings/kaiten-automation`. Открывается двойным
кликом по `index.html`, дев-сервер не нужен.

```
index.html          разметка страницы
styles.css          стили, 86 КБ
assets/brand/       картинки: логотипы клиентов, аватары отзывов, схемы
```

## Что внутри

- **CSS отдельным файлом и без лишнего.** Из бандла вырезаны правила, чьи классы на
  странице не встречаются: 199 → 85 КБ. Переменные темы, `:root`, теговые и
  базовые стили сохранены целиком — на них держатся палитра и типографика.
- **JS удалён.** Интерактивные секции (табы, слайдер отзывов) показывают
  состояние по умолчанию — первый таб, первый экран ленты.
- **Шрифт с Google Fonts.** Локальные `@font-face` вели на `/_next/static/media`
  и в отдельном файле не резолвились; заменены одной ссылкой на Roboto
  400/500/600/700. Нужен интернет — иначе сработает системный запасной шрифт.
- **Картинки локальные.** Пути переписаны с `/brand/…` на `assets/brand/…`,
  сами файлы лежат рядом.

## Как пересобрать

```bash
pnpm --filter @kaiten/web dev            # поднять дев-сервер на :3000
node scripts/build-static-html.mjs kaiten-automation "Модуль «Автоматизации»/index.html" --split-css
```

Скрипт делает всё, кроме копирования картинок, — их пути после пересборки снова
станут абсолютными.
