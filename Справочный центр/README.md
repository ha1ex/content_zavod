# Справочный центр — статичная выгрузка лендинга

Автономная копия страницы `/landings/kaiten-help-center`. Открывается двойным
кликом по `index.html`, дев-сервер не нужен.

```
index.html          разметка страницы
styles.css          стили
assets/brand/       картинки
```

## Что внутри

- **CSS отдельным файлом и без лишнего.** Из бандла вырезаны правила, чьи классы
  на странице не встречаются. Переменные темы, `:root`, теговые и базовые стили
  сохранены целиком — на них держатся палитра и типографика.
- **JS удалён, кроме масштабирования мокапов.** В конце страницы остаётся
  двенадцать строк: они ужимают мокапы фиксированной ширины под колонку — ровно
  то, что в приложении делает компонент `MockFit`. Без них мок вылезал за
  колонку на планшете и тянул горизонтальную прокрутку.
- **Интерактива нет.** Аккордион «Справочный центр в стиле вашей компании» и
  карусель возможностей показывают состояние по умолчанию — первый пункт,
  первый экран. FAQ раскрывается: он собран на `<details>`.
- **Шрифт с Google Fonts.** Локальные `@font-face` вели на `/_next/static/media`
  и в отдельном файле не резолвились; заменены ссылкой на Roboto 400/500/600/700.
- **Картинки локальные.** Пути переписаны с `/brand/…` на `assets/brand/…`.

## Как пересобрать

```bash
pnpm --filter @kaiten/web dev            # поднять дев-сервер на :3000
node scripts/build-static-html.mjs kaiten-help-center "Справочный центр/index.html" --split-css
cp apps/web/public/brand/cta-product.png "Справочный центр/assets/brand/cta-product.png"
```

После пересборки пути к картинкам снова становятся абсолютными (`/brand/…`) —
поменяйте их на `assets/brand/…`.
