Частые вопросы о Справочном центре

  • Можно ли использовать Справочный центр без Службы поддержки?

    Да. Вы можете создать Справочный центр с инструкциями, FAQ, документацией, новостями и другими материалами без подключения сервисов Службы поддержки. Если позже захотите принимать обращения пользователей, сервисы можно подключить дополнительно.

  • Справочный центр подходит только для поддержки клиентов?

    Нет. Его можно использовать как для клиентов и партнеров, так и внутри компании — например, для IT, HR, бухгалтерии, юридического отдела или АХО. Вы сами определяете, какие материалы публиковать и какие сервисы Службы поддержки подключать.

  • Можно ли оформить Справочный центр в стиле компании?

    Да. Можно добавить логотип, название и фирменные цвета, а также настроить внешний вид писем для пользователей. Также Справочный центр можно разместить на домене вашей компании.

  • Что происходит с заявкой после отправки?

    Обращение из Справочного центра создается отдельной карточкой на доске Kaiten. Команда может назначить ответственного, работать с заявкой по своему процессу и менять ее статус, а пользователь — следить за обращением в Справочном центре.

  • Как пользователи находят нужные материалы?

    Через разделы Справочного центра и поиск по опубликованным материалам. А при создании заявки Kaiten может дополнительно предложить подходящие статьи, чтобы пользователь попробовал найти решение самостоятельно.

  • Можно ли создать несколько Справочных центров?

    Да. Вы можете создать несколько Справочных центров для разных задач и аудиторий — например, отдельные для клиентов, сотрудников, партнеров или разных продуктов. В каждом можно настроить свои материалы, оформление и сервисы Службы поддержки.

  • Нужно ли разрабатывать отдельный сайт для Справочного центра?

    Нет. Справочный центр создается и настраивается прямо в Kaiten без разработки. Добавьте нужные материалы, настройте оформление и при необходимости подключите сервисы Службы поддержки. Готовый Справочный центр можно разместить на собственном домене
